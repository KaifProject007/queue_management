2. Erlang C Queueing Theory ($M/M/c$)

• Offered Load: $a = \lambda / \mu$
• Counter Utilization: $\rho = a / c$
• Wait Time: $W_q = C(c, a) / (c\mu - \lambda)$
• Queue Length: $L_q = \lambda \cdot W_q$ (Little's Law)
