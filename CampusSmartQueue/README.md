## 🌟 Upgrades from 1.0 Proposal

1. **Autonomous Data Ingestion (Cancelled QR/Google Forms Survey)**:
   - Replaced student manual forms with multi-source telemetry and a calibrated Kaggle campus mobility dataset.
   - Enforces cryptographic **Salted SHA-256** roll number hashing and the `< 10` group suppression privacy rule.
   - Saves nightly CSV backups to `data/crowd_index_backup.csv`.

2. **Full-Stack Modern Web UI (No Streamlit)**:
   - Single-Page Application (SPA) built with modern HTML5, CSS3, ES6 JavaScript, Three.js, and Chart.js.
   - **3D Architectural Campus Twin**: Real-time 3D rendered pavilion of AISSMS COE with OrbitControls (drag to rotate, scroll to zoom), Default / Aerial 2D / Day-Night lighting modes, and floating live crowd billboards.
   - **Interactive Virtual Campus Simulation Clock**: Play/pause and quick jump controls (09:00 AM Xerox rush, 12:30 PM Lunch rush, 03:30 PM Quiet study).
   - **Digital Virtual FastPass Token Dispenser**: Instant virtual queue tokens with department selection and live ETA call predictions.
   - **Weekly Footfall Heatmap Matrix**: Comprehensive 6-day (Mon–Sat) by 20-slot interactive crowd matrix.
   - **Erlang C Multi-Server Queue Simulator**: Real-time slider simulator with animated student avatars and active service counters.
   - **Best Time to Go**: Intelligent recommendation engine highlighting the quietest visiting windows.

3. **Machine Learning & Mathematical Foundations**:
   - **Erlang C Formula ($M/M/c$)**: Computes waiting time $W_q$, queue length $L_q$, and counter utilization $\rho$.
   - **Automated Gating Tournament**: Benchmarks LightGBM Regressor against historical rolling baseline; strictly serves the winning model.
   - **KMeans Schedule Clustering**: Identifies 3 footfall archetypes (Morning Rush, Mid-day Dining, Afternoon Study).
   - **Z-Score Surge Flagging**: Real-time crowd emergency detector ($Z \ge 2.0\sigma$).

## 📡 REST API Endpoints (Slide 14 + Modern Features)

- `GET /api/places`: Lists all campus facilities and their capacities.
- `GET /api/crowd`: Returns current/target crowd index, Low/Med/High level, and Erlang C queue metrics.
- `GET /api/forecast?place_id=...`: Hourly 08:00 - 18:00 forecast curve generated by LightGBM.
- `GET /api/best-time?place_id=...`: Top quietest upcoming slots with lowest wait times.
- `POST /api/take-token`: Generates a virtual queue pass with student roll, department, and live call ETA.
- `GET /api/weekly-heatmap?place_id=...`: Returns a 6-day x 20-slot crowd matrix.
- `GET /api/departments`: Lists all official AISSMS COE engineering departments.
- `POST /api/queue-simulator`: Interactive Erlang C sandbox calculator.
- `GET /api/status`: Campus live overview with virtual clock and anomaly flags.
- `POST /api/simulate-tick`: Advances virtual campus clock.
- `GET /api/analytics`: Model MAE scorecard, dataset stats, and KMeans clusters.
- `POST /api/subscribe`: Web Push subscription endpoint.
